# 🥁 TaalTaraang – Tabla Web Community App

## 📖 Introduction

**TaalTaraang** is a web-based community platform specially built for tabla enthusiasts.  
It solves a common problem faced by tabla players — finding trusted tabla shops, quality accessories, and a supportive music community.

The application is divided into two main modules:

- 👤 User Module  
- 🛠 Admin Module  

---

# 👤 User Module

The User Module contains the following features:

---

## 🏪 1. Shop Module – Trusted Tabla Shops Directory

Buying a tabla is not like buying a regular product online.  
A tabla is like jewelry — it requires trust, sound quality assurance, and expert recommendation.

Many players struggle to find reliable shops in their area.  
TaalTaraang solves this problem by:

- Providing a list of verified tabla shops  
- Allowing users to post trusted shop recommendations  
- Building a community-driven trusted directory  
- Helping beginners confidently purchase quality tabla sets  

This module brings the **community aspect** into action.

---

## 🤖 2. ML Beat Classifier (Python-Based)

This feature uses Machine Learning to classify tabla taals.

### 🔹 Features:
- Users can upload an audio file  
- The ML model analyzes the rhythm  
- The system classifies the Tabla Taal  

### 🔹 Built Using:
- Python  
- Audio processing techniques  
- Machine Learning algorithms  

### 🔹 Benefits:
- Helps beginners understand taals  
- Assists music students during practice  
- Encourages rhythm exploration  

---

## 🛍 3. Accessories Marketplace Module

TaalTaraang provides a dedicated marketplace for tabla accessories.

Users can purchase:

- Tabla bags  
- Covers  
- Hammers  
- Maintenance tools  
- Other essential accessories  

This ensures users get everything related to tabla in one place.

---

## 💳 4. Integrated Payment Gateway

The platform includes secure online payment integration.

### 🔹 Features:
- Secure payment processing  
- Order confirmation system  
- Smooth checkout experience  

This ensures safe and reliable transactions.

---

# 🛠 Admin Module

The Admin Module allows full platform management.

### 🔹 Admin Capabilities:

- Manage users  
- Add, update, or remove marketplace items  
- Verify shop listings before approval  
- Manage and track user orders  
- Monitor platform activities  

This ensures quality control and trust within the platform.

---

# 🎯 Objective

The main goals of TaalTaraang are:

- Build a trusted digital community for tabla players  
- Simplify buying tabla and accessories  
- Combine music and technology using Machine Learning  
- Create a one-stop platform for tabla enthusiasts
